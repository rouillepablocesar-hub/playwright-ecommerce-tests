# Playwright E-commerce Test Suite

Test suite de automatización para validar flujo de compra en aplicación e-commerce.

## Requisitos
- Node.js 18+
- npm

## Instalación
```bash
npm install
```

## Correr tests
```bash
npx playwright test
```

## Estructura del proyecto
- `tests/` - Casos de prueba automatizados
- `fixtures/` - Datos y helpers reutilizables
- `playwright.config.ts` - Configuración de Playwright

## Stack
- **Playwright** - Framework de testing
- **TypeScript** - Lenguaje
